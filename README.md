# WMS SDK

**English** | [ภาษาไทย](README.th.md)

An SDK for designing WMS (Warehouse Management System) databases, shared by many factories.
Python + SQLAlchemy 2.0, targeting Microsoft SQL Server.

- **core**: tables every warehouse needs: plants, users, products, warehouses / zones / locations, pallets, QC, event log
- **interface**: tables every factory has with different columns; the SDK fixes the key, the factory adds columns
- **feature**: optional add-ons: machines, brand, floor_map (maps + map builder), routing (forklift routes), tasks (work orders + location reservations)
- Installable as a package; each factory writes its own project, generated by `wms-sdk init` (see [Building a factory project](docs/en/factory-guide.md#quick-start-generate-the-project)). Full example: `examples/reference_factory/`

## Install

```bash
pip install "wms-sdk[mssql] @ git+https://github.com/Nextjingjing/wms-sdk.git@v0.1.2"
```

The repository is private; see [Installation](docs/en/installation.md) for sign-in options.

## Develop

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt   # Linux / macOS: .venv/bin/python
.venv\Scripts\python -m pytest                                # all tests (SQLite)
.venv\Scripts\python -m dev.create_db --mock                  # dev.sqlite with sample data
```
