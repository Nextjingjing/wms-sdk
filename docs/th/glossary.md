# อภิธานศัพท์

**ภาษาไทย** | [English](../en/glossary.md)

## สถานที่

```
plant C221 (TL)
 └─ warehouse W1
     └─ zone 1
         └─ location tl-w1-1-0101   ← ที่วางพาเลทหนึ่งจุดที่มีรหัส
```

| คำ | ภาษาไทย | ความหมาย | ตาราง |
|---|---|---|---|
| **plant** | โรงงาน | site ของโรงงาน รหัสเช่น `C221` | `plants` |
| **warehouse** | คลัง | อาคารหรือพื้นที่เก็บของในโรงงาน รหัสไม่ซ้ำภายในโรง | `warehouses` |
| **zone** | โซน | พื้นที่ภายในคลัง เป็นแบบแบน ไม่ซ้อนกัน | `zones` |
| **location** | ตำแหน่ง | ที่วางพาเลทหนึ่งจุดที่มีรหัสที่คนใช้เรียก (เช่น `tl-w1-1-0101`) | `locations` |
| **enabled / retired** | เปิดใช้ / เลิกใช้ | `is_enabled = 0` ปิดชั่วคราว; `deleted_at` เลิกใช้ถาวร | `locations` |

### ตัวอย่างอ้างอิงเก็บพาเลทยังไง (วางซ้อนบนพื้น)

ตัวอย่างอ้างอิงวางพาเลทซ้อนบนพื้นเป็นแนว คำเหล่านี้เป็นของตัวอย่างนั้น (อยู่ใน `location_properties`) ไม่ได้อยู่ใน SDK:

```
        column 1 (มองจากด้านบน)              หนึ่ง row มองจากด้านข้าง
      ┌──────────────┐
row 1 │ [ ][ ]       │  ← location tl-w1-1-0101        level 2  [ ][ ]
row 2 │ [ ][ ]       │  ← location tl-w1-1-0102        level 1  [ ][ ]
row 3 │ [ ][ ]       │  ← location tl-w1-1-0103                 slot 1 2
      └──────────────┘
        ▲ ปากช่อง: forklift เข้าทางนี้
```

| คำ | ภาษาไทย | ความหมาย |
|---|---|---|
| **column** | แนว / ล็อก | แนวยาวที่มีหลาย row |
| **row** | แถว | ตำแหน่งหนึ่งตามแนว column; **หนึ่ง row = หนึ่ง location** |
| **level** | ชั้น | พาเลทซ้อนสูงชั้นที่เท่าไหร่ใน row (`max_level` = ความจุ) |
| **slot** | ช่อง | ตำแหน่งที่วางเรียงข้างกันใน row (`sub_column` = ความจุ) |
| **position** | ตำแหน่งพาเลท | location + level + slot: จุดที่พาเลทหนึ่งใบวางอยู่ |

## สินค้า

| คำ | ภาษาไทย | ความหมาย | ตาราง |
|---|---|---|---|
| **product / sku** | สินค้า | สินค้าหนึ่งรายการ ระบุด้วย `sku` | `products` |
| **pallet** | พาเลท | พาเลทจริงที่ใช้ซ้ำได้ มีรหัส QR / LPN | `pallets` |
| **load** | ของบนพาเลท | ของที่อยู่บนพาเลทตอนนี้: 1 sku, 1 lot, จำนวน (NULL ทั้งหมด = ว่าง) | `pallets` |
| **lot** | ล็อตผลิต | ชุดการผลิต เก็บเป็น `lot_no` บนพาเลท | `pallets` |
| **QC status** | สถานะ QC | `waiting` / `locked` / `passed` ส่งได้เฉพาะพาเลทที่ passed | `pallets` |
| **on-hand stock** | ยอดคงเหลือ | `SUM(qty)` ของพาเลท ไม่มีตาราง balance | |

## ส่วนประกอบของ SDK

| คำ | ภาษาไทย | ความหมาย |
|---|---|---|
| **core** | แกนกลาง | ตารางที่ทุกคลังมี |
| **interface** | interface | ตารางของ SDK ที่ key ตายตัว แต่ละโรง subclass ครั้งเดียวแล้วเพิ่มคอลัมน์ (`*Base`) |
| **feature** | feature เสริม | ตารางและฟังก์ชันเสริม มีเมื่อ import เท่านั้น |
| **lookup** | ตาราง lookup | ชุดค่าเล็ก ๆ ที่แต่ละโรง seed เอง (`roles`, `brands` ...) key เป็น `code` ที่อ่านรู้เรื่อง |
| **seed** | ข้อมูลตั้งต้น | แถวของตาราง lookup ที่โรงงานใส่ก่อนใช้งาน |
| **operation** | การกระทำ | การกระทำหนึ่งครั้งของผู้ใช้; `start_operation` ให้ทุก event ของมันมี `operation_id` เดียวกัน |
| **event** | event | แถวใน `event_log`: การแก้ข้อมูล หรือ event ทางธุรกิจ เช่น `pallet.putaway` |
| **outbox / inbox** | กล่องขาออก / ขาเข้า | ข้อความที่รอส่งไป / ได้รับจากระบบอื่น |

## Routing (feature เสริม)

```
    A ───────────────── B ──────── D (dock)
         ▲        ▲                        vertex: A, B, D
      ปากช่อง   ปากช่อง                      ถนน: A-B, B-D (หนึ่ง edge ต่อหนึ่งทิศ)
      0101      0201                       access point: จุดที่แต่ละ location เจอถนน
```

| คำ | ภาษาไทย | ความหมาย | ตาราง |
|---|---|---|---|
| **route map** | แผนที่ถนน | ฉบับหนึ่งของเครือข่ายถนนในคลัง มี draft และ published ได้อย่างละหนึ่ง | `route_maps` |
| **vertex** | จุด | มุม ทางแยก ประตู หรือ dock | `route_vertices` |
| **road / edge** | ถนน | ทางเชื่อมระหว่างสอง vertex หนึ่ง edge ต่อหนึ่งทิศที่วิ่งได้ | `route_edges` |
| **lane mouth / access point** | ปากช่อง | จุดที่ location เจอถนน: ถนนเส้นไหน ห่างจากต้นถนนเท่าไหร่ (`offset_ratio`) ฝั่งไหน | `location_access_points` |

## Tasks (feature เสริม)

| คำ | ภาษาไทย | ความหมาย | ตาราง |
|---|---|---|---|
| **task** | งาน | งานหนึ่งชิ้น: วางของ หยิบ จ่าย ตรวจ QC ... | `tasks` |
| **active status** | สถานะที่ยังไม่เสร็จ | สถานะที่โรงงานนับว่ายังไม่เสร็จ (`active_statuses`) | |
| **reservation** | การจอง | ปลายทางของงานที่ยังไม่เสร็จ งานอื่นที่ยังไม่เสร็จจะใช้ที่เดียวกันไม่ได้ | `tasks` (unique index) |
| **reference** | เลขอ้างอิง | เอกสารภายนอก เช่น ใบสั่งขาย ที่งานหลายงานใช้ร่วมกัน | `tasks` (คอลัมน์ของโรงงาน) |
